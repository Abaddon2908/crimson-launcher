# NLauncher — мониторинг серверов Minecraft

Сайт работает при поддержке [NeoDev](https://neo-dev.ru).

Сайт-мониторинг Minecraft-серверов, связанный с NLauncher. Здесь продаётся реклама и рассылаются новости.

## Что умеет

**Для игроков**
- Топ серверов: PROMO-места сверху, дальше по голосам за месяц. Есть поиск и фильтр по режимам.
- Страница сервера: онлайн, пинг, версия, MOTD и график онлайна за 24 часа, 7 дней и 30 дней. IP копируется в один клик.
- Голосование раз в сутки, повтор по нику или IP не засчитывается. Награды выдаёт плагин сервера через вебхук.

**Для владельцев серверов** (кабинет)
- Регистрация, добавление и редактирование сервера, отправка на модерацию.
- Покупка рекламы:
  - **PROMO** — над топом на сайте и в NLauncher;
  - **баннер** — на главной NLauncher и на сайте;
  - **выделение** — подсветка карточки в топе.
- Оплата картой или кошельком **ЮMoney** и криптовалютой через **Heleket**. Реклама включается автоматически после оплаты.
- Очередь: если все места заняты, в кабинете видна дата старта. При продлении новый срок начинается после текущего.

**Голосование и награды**
- Голоса доставляются на сервер по стандартному протоколу Votifier: v1 (публичный ключ, VotifierPlus/Votifier) и v2 (токен NuVotifier). В кабинете есть кнопка «Сохранить и проверить Votifier», инструкция для владельцев — на странице `/votifier`.
- Оценка сервера звёздами, последние голоса, топ голосующих за месяц. Интервал между голосами задаётся в админке.

**Подборки и SEO-страницы**
- Каталог из 69 тегов в 6 группах (режимы, мини-игры, донат, возможности, моды, доступ) и диапазон версий «от — до».
- Страницы подборок `/servera-vyzhivanie/`, `/servera-1.21/`, каталог `/servera/`, новые сервера `/new`, «Избранное» `/favorites`.

**Страница сервера**: места в рейтинге (общий, по голосам, по онлайну), средний онлайн за 7 дней, аптайм за 30 дней, частые вопросы (FAQ), похожие сервера, счётчик копирований IP, кнопка «В избранное».

**Виджеты для сайтов серверов** (Кабинет → Виджеты): живая кнопка голосования со счётчиком, SVG-виджет онлайна, баннеры 88×31 и 180×44.

**Промо-баллы и купоны**
- Промо-баллы: любое количество на срок от 7 до 180 дней. Порядок в топе: PROMO-места, затем сервера по сумме баллов, затем по голосам. Пакетная скидка 5–15 %, скидка за долгий срок.
- Купоны на скидку (Админка → Купоны), выбор цвета выделения.

**Статистика для владельца** (Кабинет → Статистика): просмотры страницы, копирования IP и голоса по дням, дни с рекламой и её эффект.

**«Сервер в игре»** (платная услуга)
- Оплаченный сервер появляется **первым в списке «Сетевая игра» внутри Minecraft** у каждого игрока NLauncher.
- Лаунчер перед запуском дописывает его в `servers.dat` сборки. Свои сервера игрока не трогаются.
- Когда срок заканчивается, лаунчер сам убирает этот сервер из списка.

**Админка** (`/admin`)
- **Выдать услугу**: любая услуга (PROMO, баннер, выделение, «в игре») на любой срок. Можно бесплатно или с суммой для учёта оплат вне сайта, с комментарием; старт сразу или после текущей.
- Карточка сервера: услуги, продление или сокращение срока, досрочное завершение, смена владельца, голоса с IP, удаление накрученных голосов.
- Поиск по серверам, заказам и пользователям, выгрузка заказов в CSV.
- Журнал всех действий администраторов.
- Пользователям можно задать новый пароль.
- Обзор: выручка, график за 30 дней, активная реклама.
- Модерация серверов: одобрить, отклонить с причиной, удалить, выдать PROMO бесплатно.
- Заказы: ручное подтверждение оплаты и отмена.
- Тарифы: цены, сроки и число мест.
- Новости — показываются на сайте и в лаунчере.
- Пользователи: выдать админа, забанить.
- Настройки: ключи платёжек, название, баннер по умолчанию.

**Связь с NLauncher**: `GET /api/launcher/feed.json` отдаёт баннер, новости, PROMO-сервера и топ.

## Запуск на сервере с панелью Hestia (nlauncher.ru)

Если на сервере уже стоит Hestia и работают другие сайты, используйте этот вариант. Сайт запускается в Docker на `127.0.0.1:3080`, домен и SSL обслуживает nginx панели.

1. **DNS.** У регистратора домена создайте A-записи `@` → IP сервера и `www` → IP сервера.
   Если DNS домена ведётся в самой Hestia (вкладка DNS), добавьте зону там, а у регистратора укажите NS-серверы панели.
2. **Домен в панели.** WEB → «Добавить веб-домен» → `nlauncher.ru`, алиас `www.nlauncher.ru`. Галочку SSL пока **не** ставьте.
3. **По SSH под root:**

```bash
cd /opt && git clone https://github.com/Abaddon2908/crimson-launcher.git
```
```bash
cd /opt/crimson-launcher/site && bash deploy/hestia-setup.sh nlauncher.ru
```

Скрипт:
- поставит Docker, если его нет;
- спросит email и пароль администратора;
- запустит сайт;
- установит в Hestia шаблон nginx `nlauncher` и применит его к домену;
- выпустит сертификат Let's Encrypt.

Если DNS ещё не обновился, сертификат не выпустится. Скрипт напишет команду, которую нужно повторить позже.

Обновление сайта:

```bash
cd /opt/crimson-launcher && git pull && cd site && docker compose -f docker-compose.hestia.yml up -d --build
```

## Запуск на чистом VPS (Docker + Caddy)

Подойдёт любой VPS с Docker: 1 ГБ ОЗУ хватает с запасом.

1. Направьте домен (A-запись) на IP сервера.
2. На сервере выполните:

```bash
git clone https://github.com/Abaddon2908/crimson-launcher.git
```
```bash
cd crimson-launcher/site && cp .env.example .env && nano .env
```
```bash
docker compose up -d --build
```

Caddy сам выпустит HTTPS-сертификат для домена из `DOMAIN`. Войдите на сайт под `ADMIN_EMAIL` / `ADMIN_PASSWORD` и откройте **Админка → Настройки**.

База данных и ключ сессий лежат в `site/data/`. Резервная копия — это копия этой папки.

Обновление:

```bash
git pull && docker compose up -d --build
```

## SEO и метрики

Что уже сделано:
- У каждой страницы свои title и description, canonical, `noindex` для админки, кабинета, входа, результатов поиска и 404.
- Превью для соцсетей и мессенджеров (Open Graph и Twitter) с картинкой 1200×630. У сервера с обложкой в превью попадает его обложка.
- Понятные адреса серверов `/server/12-craftlands`; старые `/server/12` перенаправляются на них редиректом 301.
- `robots.txt`, `sitemap.xml` (все сервера и режимы), манифест и иконки для телефонов.
- Структурированные данные JSON-LD: WebSite с поиском, Organization, ItemList (топ), BreadcrumbList, SoftwareApplication (лаунчер).
- Сжатие gzip. Lighthouse: SEO 100, производительность 97–99, доступность 96–100.

Что нужно сделать вам (Админка → Настройки → «SEO и метрики»):
1. **Яндекс Метрика:** создать счётчик на metrika.yandex.ru и вписать его номер.
2. **Яндекс Вебмастер:** добавить сайт, выбрать способ «Мета-тег» и вписать код. Затем в разделе «Индексирование → Файлы Sitemap» добавить `https://nlauncher.ru/sitemap.xml`.
3. **Google Search Console:** «Префикс URL», способ «Тег HTML», вписать код. Затем «Файлы Sitemap» → `sitemap.xml`.
4. **Google Analytics** (по желанию): вписать идентификатор `G-…`.

Когда включены счётчики, сайт показывает уведомление о cookie (требование 152-ФЗ).

## Выкладка новой версии лаунчера

Кнопка «Скачать» на сайте и ссылка https://nlauncher.ru/download всегда ведут на самую новую версию из папки загрузок. Лаунчеры с более старой версией показывают игрокам кнопку «Доступно обновление».

**Через админку (проще всего):** Админка → **Лаунчер** → перетащите `NLauncher-Setup-X.Y.Z.exe` из GitHub Releases. Файл не переименовывайте: версия берётся из имени.

**По SSH:** положите файл в папку загрузок:

```bash
cd /opt/crimson-launcher/site/data/downloads && wget https://github.com/Abaddon2908/crimson-launcher/releases/latest/download/NLauncher-Setup-0.2.6.exe && chown 1000:1000 *.exe
```

Папку `public_html` в Hestia для этого использовать нельзя: домен целиком обслуживает сайт мониторинга, поэтому файлы оттуда не видны.

## Подключение оплаты

### ЮMoney
1. Нужен кошелёк ЮMoney (лучше идентифицированный).
2. Откройте https://yoomoney.ru/transfer/myservices/http-notification:
   - адрес: `https://ВАШ-ДОМЕН/pay/yoomoney/notify`;
   - отметьте «Отправлять HTTP-уведомления» и скопируйте **секрет**.
3. В админке → Настройки введите номер кошелька и секрет.

Уведомление проверяется по подписи SHA-1 с вашим секретом и по сумме. Поддельные запросы отклоняются.

### Heleket (криптовалюта)
1. Зарегистрируйтесь на https://heleket.com и создайте мерчанта.
2. Скопируйте **UUID мерчанта** и **Payment API key** в админку → Настройки.
3. Отдельно настраивать вебхук не нужно: адрес `https://ВАШ-ДОМЕН/pay/heleket/webhook` передаётся при создании каждого счёта.

Вебхук проверяется по подписи, а статус платежа дополнительно перепроверяется запросом к API Heleket.

> Перед запуском сделайте одну тестовую покупку на минимальную сумму каждым способом. Платёжки иногда меняют детали API, а проверить это без ваших боевых ключей нельзя.

## Подключение NLauncher

В `config.json` лаунчера укажите:

```json
"feedUrl": "https://ВАШ-ДОМЕН/api/launcher/feed.json"
```

Затем пересоберите лаунчер (Actions → Build & Release → Run workflow). После этого баннер, новости, PROMO и топ в лаунчере будут браться с сайта.

## Награды за голосование (для плагина сервера)

Если владелец указал Webhook URL, после каждого голоса сайт отправляет:

```
POST <webhook>
Content-Type: application/json

{ "server_id": 1, "nickname": "Steve", "timestamp": 1731500000000, "signature": "<hex>" }
```

Подпись: `HMAC_SHA256(secret, nickname + ":" + timestamp)` в hex. Секрет показан в кабинете, в настройках сервера. Плагин проверяет подпись и выдаёт награду.

```bash
cd site && npm install
```
```bash
node scripts/demo-seed.js
```

