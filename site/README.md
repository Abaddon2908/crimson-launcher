# NeoDev Мониторинг

Сайт-мониторинг Minecraft-серверов, связанный с NLauncher. Здесь продаётся реклама и рассылаются новости.

## Что умеет

**Для игроков**
- Топ серверов: PROMO-места сверху, дальше по голосам за месяц. Есть поиск и фильтр по режимам.
- Страница сервера: онлайн, пинг, версия, MOTD и график онлайна за 24 часа, 7 дней и 30 дней. IP копируется в один клик.
- Голосование раз в сутки, повтор по нику или IP не засчитывается. Награды выдаёт плагин сервера через вебхук.

**Для владельцев серверов** (кабинет)
- Регистрация, добавление и редактирование сервера, отправка на модерацию.
- Покупка рекламы:
  - **PROMO** — над топом на сайте и в NLauncher;
  - **баннер** — на главной NLauncher и на сайте;
  - **выделение** — подсветка карточки в топе.
- Оплата картой или кошельком **ЮMoney** и криптовалютой через **Heleket**. Реклама включается автоматически после оплаты.
- Очередь: если все места заняты, в кабинете видна дата старта. При продлении новый срок начинается после текущего.

**Админка** (`/admin`)
- Обзор: выручка, график за 30 дней, активная реклама.
- Модерация серверов: одобрить, отклонить с причиной, удалить, выдать PROMO бесплатно.
- Заказы: ручное подтверждение оплаты и отмена.
- Тарифы: цены, сроки и число мест.
- Новости — показываются на сайте и в лаунчере.
- Пользователи: выдать админа, забанить.
- Настройки: ключи платёжек, название, баннер по умолчанию.

**Связь с NLauncher**: `GET /api/launcher/feed.json` отдаёт баннер, новости, PROMO-сервера и топ.

## Запуск на VPS (Docker)

Подойдёт любой VPS с Docker: 1 ГБ ОЗУ хватает с запасом.

1. Направьте домен (A-запись) на IP сервера.
2. На сервере выполните:

```bash
git clone https://github.com/Abaddon2908/crimson-launcher.git
```
```bash
cd crimson-launcher/site && cp .env.example .env && nano .env
```
```bash
docker compose up -d --build
```

Caddy сам выпустит HTTPS-сертификат для домена из `DOMAIN`. Войдите на сайт под `ADMIN_EMAIL` / `ADMIN_PASSWORD` и откройте **Админка → Настройки**.

База данных и ключ сессий лежат в `site/data/`. Резервная копия — это копия этой папки.

Обновление:

```bash
git pull && docker compose up -d --build
```

## Подключение оплаты

### ЮMoney
1. Нужен кошелёк ЮMoney (лучше идентифицированный).
2. Откройте https://yoomoney.ru/transfer/myservices/http-notification:
   - адрес: `https://ВАШ-ДОМЕН/pay/yoomoney/notify`;
   - отметьте «Отправлять HTTP-уведомления» и скопируйте **секрет**.
3. В админке → Настройки введите номер кошелька и секрет.

Уведомление проверяется по подписи SHA-1 с вашим секретом и по сумме. Поддельные запросы отклоняются.

### Heleket (криптовалюта)
1. Зарегистрируйтесь на https://heleket.com и создайте мерчанта.
2. Скопируйте **UUID мерчанта** и **Payment API key** в админку → Настройки.
3. Отдельно настраивать вебхук не нужно: адрес `https://ВАШ-ДОМЕН/pay/heleket/webhook` передаётся при создании каждого счёта.

Вебхук проверяется по подписи, а статус платежа дополнительно перепроверяется запросом к API Heleket.

> Перед запуском сделайте одну тестовую покупку на минимальную сумму каждым способом. Платёжки иногда меняют детали API, а проверить это без ваших боевых ключей нельзя.

## Подключение NLauncher

В `config.json` лаунчера укажите:

```json
"feedUrl": "https://ВАШ-ДОМЕН/api/launcher/feed.json"
```

Затем пересоберите лаунчер (Actions → Build & Release → Run workflow). После этого баннер, новости, PROMO и топ в лаунчере будут браться с сайта.

## Награды за голосование (для плагина сервера)

Если владелец указал Webhook URL, после каждого голоса сайт отправляет:

```
POST <webhook>
Content-Type: application/json

{ "server_id": 1, "nickname": "Steve", "timestamp": 1731500000000, "signature": "<hex>" }
```

Подпись: `HMAC_SHA256(secret, nickname + ":" + timestamp)` в hex. Секрет показан в кабинете, в настройках сервера. Плагин проверяет подпись и выдаёт награду.

## Локальная разработка

```bash
cd site && npm install
```
```bash
node scripts/demo-seed.js
```
```bash
ADMIN_EMAIL=admin@local ADMIN_PASSWORD=admin12345 npm run dev
```

Откройте http://localhost:3000. Нужен Node.js 22.13+: используется встроенный SQLite, нативные модули не нужны.
